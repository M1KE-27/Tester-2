# Performance Lab

Experimental web application focused on maximum perceived and measured web performance.

## Stack

- Next.js
- React + TypeScript
- Tailwind CSS
- GSAP
- Motion (Framer Motion)
- Three.js / React Three Fiber
- Rust + WebAssembly
- Node.js + Fastify
- PostgreSQL / Supabase
- Vercel

## Goals

- Responsive experience from mobile to ultrawide displays
- Fast initial load and minimal client JavaScript
- Lazy-loaded 3D and WebAssembly workloads
- Smooth GPU-friendly animations
- Real client-side performance measurements
- Accessible interaction and reduced-motion support

## Experiments

- Interactive 3D scene
- Animation and scroll performance
- WebAssembly vs JavaScript processing
- Client performance benchmark
- Architecture and runtime demonstrations

## Status

This repository is an experimental project. The architecture is intentionally designed to test different rendering, animation, WebGL and WebAssembly strategies rather than represent a production product.

## Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
